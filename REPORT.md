# Ночной прогон: пять индонезийских детективов в читалку

Ветка `night/belajar-bahasa-sdelay-mne-5-knig-na-ind`, три коммита.
Задача: «5 книг на индонезийском в духе авторов, похожих на Агату Кристи,
и добавить их в проект с русским переводом».

## Что сделано

Пять новых книг в `/reading`, каждая — законченный детектив с разгадкой,
написанный тем же простым разговорным индонезийским, что и две уже лежавшие
в проекте книги. У всех пяти **перевод по предложениям — 100%** и
**глоссарий (перевод по наведению на слово) — 100%**.

| книга | в манере | глав | слов | предложений |
|---|---|---|---|---|
| **SURAT DARI BOGOR** — «Письмо из Богора» | Артур Конан Дойл | 7 + 2 | 1400 | 254 |
| **HUJAN DI STASIUN TUGU** — «Дождь на вокзале Тугу» | Жорж Сименон | 6 + 2 | 982 | 188 |
| **PINTU YANG TERKUNCI** — «Запертая дверь» | Джон Диксон Карр | 6 + 2 | 1031 | 191 |
| **LONCENG DI KAMPUS** — «Колокол в кампусе» | Дороти Л. Сэйерс | 6 + 2 | 869 | 170 |
| **PUKUL TUJUH LEWAT LIMA** — «Пять минут восьмого» | Эллери Куин | 7 + 2 | 1115 | 189 |

«+2» — вступление «Buat Pembaca» и список персонажей: в читалке они тоже
главы. Итого ~5400 слов индонезийской прозы и ~990 переведённых предложений.

У каждой книги есть приложение (страница `/reading/<slug>/appendix`) с тремя
частями: чей это стиль и почему, таблица «честной игры» (какая улика в какой
главе и что она значит) и разбор грамматики, которая в этой книге чаще всего
повторяется. Обложки — SVG, в одной серии с существующими.

Все пять — «честная игра»: разгадка выводится из текста, у последней даже есть
отдельная глава «Tantangan untuk Pembaca» — вызов читателю в духе Куина.

## Решения и почему

**Почему не `translate-reading.mjs`.** Штатный маршрут перевода дёргает
`claude -p`; в этой песочнице бинарь недоступен (`claude not found`, попытки
проверить другие пути заблокированы). Поэтому перевод написан мной вручную.

**Отсюда — новый формат исходника.** Ключ перевода в проекте — точный текст
предложения после разбора `build-reading.mjs`. Писать `translations.json`
руками рядом с `.md` значит выравнивать сотни ключей на глазок: разойдись
ключ на один символ — абзац молча останется без кнопки ⇄, и в интерфейсе это
никак не видно. Поэтому книги написаны в `data/reading/duo/<slug>.duo.md`,
где на каждой строке `Kalimat asli. | Перевод.`, а
[`scripts/build-duo.mjs`](scripts/build-duo.mjs) разворачивает это в обычный
`.md` и в `translations.json` из одного источника. Разойтись ключам негде.
Скрипт заодно ругается на строки, которые склеятся при разборе.

**Глоссарий не переводился заново.** Словоформы у книг на одном языке общие:
`saya`, `nggak`, `bilang` в новой книге значат ровно то же.
[`scripts/seed-glossary.mjs`](scripts/seed-glossary.mjs) берёт готовые записи
из уже переведённых книг и из врезок «Kata Baru» самой книги. Так покрылось
~85%. Остаток (135 словоформ — имена, топонимы, формы на `-nya`, пассивы на
`di-`) переведён руками один раз в общий `data/reading/id-extra.glossary.json`,
который лежит в пуле первым.

**Проверка вместо доверия.** [`scripts/check-reading.mjs`](scripts/check-reading.mjs)
проходит по собранным книгам и печатает, у скольких предложений нет перевода и
сколько словоформ мимо глоссария. Именно он поймал три реальные ошибки:
ключи глав уезжали вместе с номером (`1. Tetangga Baru` вместо
`Tetangga Baru`), ключи с разметкой не совпадали с чистым текстом, а врезки
«Kata Baru» разваливались на заголовок и абзац — и переставали быть
словариками.

**Что осталось нетронутым.** Ни одного `.ts`/`.tsx` не изменено: читалка сама
находит книги по `data/reading/*.md` + `.json` (`bookSlugs()` в
`lib/reading.ts`). Витрина, оглавление, перевод по наведению, кнопка ⇄ и
запасной голос браузера работают на новых книгах без единой правки кода.

## Как проверить за 5 минут

```bash
git switch night/belajar-bahasa-sdelay-mne-5-knig-na-ind
npm run reading:check          # у всех ли книг есть перевод и глоссарий
npm install && npm run dev     # открыть http://localhost:3000/reading
```

Ожидаемый вывод `reading:check` — у пяти новых книг ровно
`перевод 100%, глоссарий 100%`:

```

  ✗ без перевода: 14
hujan-di-stasiun-tugu: глав 8, предложений 188, перевод 100%, глоссарий 100% (301/301)
kabut-di-lembang: глав 25, предложений 2351, перевод 100%, глоссарий 100% (1532/1532)
lonceng-di-kampus: глав 8, предложений 170, перевод 100%, глоссарий 100% (266/266)
perahu-terakhir: глав 23, предложений 1685, перевод 100%, глоссарий 100% (929/929)
pintu-yang-terkunci: глав 8, предложений 191, перевод 100%, глоссарий 100% (298/298)
pukul-tujuh-lewat-lima: глав 9, предложений 189, перевод 100%, глоссарий 100% (288/288)
surat-dari-bogor: глав 9, предложений 254, перевод 100%, глоссарий 100% (338/338)
```

Четырнадцать «непереведённых» у `ai-business-english` — не регресс: это
абзацы, изначально написанные по-русски (обращение к читателю во вступлении),
переводить их некуда. Проверка о них не знает и считает дырой; при желании
это стоит доучить, но трогать чужую книгу в этом прогоне я не стал.

Глазами стоит посмотреть:

1. `/reading` — пять новых карточек с обложками, у каждой значок
   «перевод по предложениям».
2. Любая глава, например `/reading/pukul-tujuh-lewat-lima/6` — наведение на
   слово даёт перевод, кнопка ⇄ у абзаца даёт перевод предложения,
   тумблер «перевод везде» в шапке.
3. `/reading/surat-dari-bogor/appendix` — таблица улик и разбор грамматики.

Пересборка книги с нуля:

```bash
npm run reading:duo -- surat-dari-bogor
npm run reading:build -- surat-dari-bogor
npm run reading:glossary -- surat-dari-bogor
npm run reading:check -- surat-dari-bogor
```

## Что не сделано

**`npm run build` не прогонялся.** В этом worktree нет `node_modules`, а
устанавливать пакеты в ночном прогоне запрещено (`sh: next: command not found`).
Риск при этом близок к нулю: изменены только данные, три `.mjs`-скрипта, пять
SVG, `package.json` (добавлены три npm-скрипта) и `README.md`; TypeScript не
тронут. Всё же перед мержем стоит один раз собрать проект локально.

**Озвучки нет.** MP3 генерирует `generate-audio-voicer.mjs`, ему нужен
`VOICER_API_KEY` и квота символов — это решение владельца ключа, не ночного
прогона. На пять книг это 31 388 символов (7944 + 5916 + 5994 + 5119 + 6435 —
цифры печатает `reading:build`). Пока MP3 нет, кнопка 🔊 читает системным
индонезийским голосом, а на витрине у книг честно стоит «голос браузера».
Голоса книгам тоже ещё не назначены (см. карту голосов в скрипте озвучки).

**Индонезийский не вычитан носителем.** Язык намеренно держится в узком
регистре учебной прозы — короткие фразы, разговорные `nggak/udah/aja/banget`,
те же конструкции, что в двух существующих книгах. Но это текст, написанный
не носителем, и перед публикацией его стоит показать живому человеку;
вероятнее всего править придётся не грамматику, а интонацию реплик.

**Не проверял на узких экранах.** Разметка книг не отличается от старых
(абзацы, цитаты, врезки-словарики), так что сюрпризов быть не должно, но
руками я этого не смотрел.

## Файлы

```
scripts/build-duo.mjs                 новый: duo-исходник → .md + translations.json
scripts/seed-glossary.mjs             новый: глоссарий из соседних книг и врезок
scripts/check-reading.mjs             новый: проверка полноты перевода и глоссария
data/reading/duo/*.duo.md             5 двуязычных исходников (источник правды)
data/reading/id-extra.glossary.json   общий словарик имён и редких форм
data/reading/<slug>.{md,json,translations.json,glossary.json,words.json}
public/reading/<slug>.svg             5 обложек
package.json                          reading:duo, reading:glossary, reading:check
README.md                             раздел про duo-маршрут
```

Править книги надо в `duo/<slug>.duo.md` и пересобирать: `.md` и
`translations.json` — производные, ручные правки в них перетрутся.
